Toyota Timing Belt OEM Part Number Cross Reference
This Toyota dataset is a brand-specific extension of the REALSHOW BELT Automotive Timing Belt OEM & Part Number Cross-Reference Database.
It contains 15 documented Toyota timing-belt cross-reference groups covering OEM references and selected aftermarket references from Gates, Dayco, Continental, and Bando, together with application and specification evidence.
What is included
The dataset separates four different evidence types:
OEM part-number relationship — original Toyota reference and related OEM numbers.
Aftermarket cross-reference — documented association with an aftermarket belt number.
Application evidence — vehicle, engine, and model-year information where the source provides it.
Specification evidence — teeth, pitch, width, length, and profile where a source supports the field.
Important interpretation rule
A cross-reference is a documented relationship, not a universal interchangeability guarantee.
The same OEM reference can appear in more than one catalog family, and regional manufacturer catalogs may use different part-number formats. Buyers should verify the exact vehicle, engine, market, tooth profile, pitch, tooth count, width, length, and manufacturer documentation before ordering.
Verification status
CROSS_REFERENCE_VERIFIED means a source explicitly documents the OEM-to-aftermarket relationship.
Records are not marked verified merely because two belts have similar dimensions.

Source policy
The dataset uses public OEM and aftermarket catalog information for identification and research. Source URLs are retained at the record level. The project does not reproduce complete proprietary manufacturer catalogs.
